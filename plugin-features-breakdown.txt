## MAIN PLUGIN STRUCTURE (menu-popup.php)
- **Class**: Menu_Popup_Plugin (Singleton pattern)
- **Initialization**: Constructor with includes/init_hooks/initialize_classes
- **Shortcode Registration**: [menu-popup] with parameters
- **Plugin Lifecycle**: activate/deactivate hooks
- **Admin Scripts**: Global enqueue with nonce and AJAX URL

### DEPENDENCIES:
- Menu_Popup_Utils (utility functions)
- Menu_Popup_Admin_* classes (dashboard, menu items, orders, branches)
- Menu_Popup_Post_Types (custom post types)
- Menu_Popup_Frontend (frontend display)
- Reservation system (optional include)
